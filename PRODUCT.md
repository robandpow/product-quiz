# Ekte vare?
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated through the user's instruction to build the recommended lightweight serverless quiz in the current directory. Static HTML, CSS and ES modules; Node development server and build script without runtime dependencies.

## Users
Norwegian-speaking adults across age groups, including parents and grandparents. Interests include exercise, outdoor activities, kitchen, DIY, makeup and self-care.

## Product Purpose
Demonstrate that believable product imagery can mislead, through their own product selections. Do not teach visual AI detection or shame participants.

## Capabilities and Constraints
Eight rounds of four isolated product images. Zero, one or two documented products per round. Multiple selection, explicit none and unsure, evidence links, reflection-focused results, local progress. Norwegian Bokmål. No leaderboard, countdown, account or analytics. User requested local implementation; no publication.

## Evidence
Retailer-sourced images and corroborating sources must be recorded separately from generated fictional concepts. A listing proves documentation, not safety, seller reliability or photographic origin. Generated concepts may resemble existing products. Image reuse permissions are unconfirmed unless explicitly documented.

## Product Principles
Confidence is not proof. Uncertainty is valid. Image provenance is disclosed after each answer. No unsupported efficacy or infant-safety claims. No false claims of universal nonexistence.

## Accessibility
Large readable controls, keyboard operation, no time pressure, image enlargement, responsive 2x2 grids, reduced motion.
